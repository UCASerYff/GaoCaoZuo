# 图标换装素材

八款高清头像由内置 ImageGen 根据用户提供的角色对照图重绘。原工具预览提供头像比例、线稿和透明构图参考。图标为独立的 1254 × 1254 透明 PNG，统一使用单人头肩像和大眼 Q 版构图。源码中的图片位于 `windows/src/gaocaozuo/assets/mascots/`，Windows 和 macOS 的发行构建使用这同一套 PNG。

| 角色 | 重绘提示 |
| --- | --- |

| Claude | 铜橙卷发、琥珀瞳、橙色菊花、深色蝴蝶结、奶油色复古肩领。 |
| Gemini | 紫蓝长发、猫耳、琥珀和粉色异瞳、星形发饰和紫白肩领。 |
