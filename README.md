# 搞操作

搞操作是一款原生 macOS 操作增强工具，把文件处理、窗口控制、剪贴板、压缩包与自定义动作集中到一个操作库，通过主窗口、菜单栏、快捷面板、访达菜单、系统服务和输入规则调用。

当前版：**V1.05 / build 6**（首版 V1.00 / build 1）。运行要求：Apple Silicon Mac、macOS 14 或更高版本。独立 Bundle ID：`com.gaoseries.GaoCaoZuo`。

## V1.05 更新

本次修复 Finder 排除应用的生成与点击复核、未知设置字段保留、终端和编辑器各自的调用语义，以及旧默认外部工具名称。用户自定义菜单名称保持不变。Terminal 仅允许明确的新窗口，无法核验的新标签调用会停止；iTerm 保留其新标签接口。新增安全硬链接恢复、自生成 AR/CPIO/CAB/ISO 样本回归与未知分卷原件保护；格式表只声明真实创建能力。

GaoAction V1 现在校验目标、时间、随机数、参数、附件摘要与文件身份，交接包复制到本应用私有目录后处理。持久记录区分已准备、已递交、待确认、完成与中断；唤起目标应用不计业务完成。本应用是截图及磁盘动作的消费者，不声明其他应用负责的提供方动作。未安装提供方或能力表不兼容时明确停止，可导出待交接包；当前不能宣称截图/贴图/OCR/磁盘清理端到端可用。

输入设备来自真实 IOHID 枚举；设备参数、支持与实机验证分开显示。新增屏幕边缘分段与冲突检查、菜单路径选择/执行、按键重复抑制及窗口进程启动身份核验。没有可靠设备事件归属时，不伪装逐设备系统调校。实验原始触控仍默认关闭。

主程序、Finder 与 Quick Look 使用独立原生本地化资源，主程序支持即时切换，Finder 菜单随快照刷新。语言目标包括简体中文、英语、日语、德语、法语、西班牙语、韩语、葡萄牙语；繁体与意大利语保留兼容选项。部分界面和动态错误仍待翻译，缺项可见回退，不宣称整套界面已完成。Quick Look 目录按钮通过公开宿主接口将压缩包选入操作面板，再由用户选择动作；宿主不支持时提供 Finder“打开方式”指引。包内内容预览、选择、提取与编辑在主程序进行。

本版尚未被确认为四款原软件的完整替代。未通过真机或格式验收的功能不计通过，原软件保留；WPS/Ai 原生模板、外部提供方、Magic Mouse、多键鼠标、多屏及部分特殊压缩变体仍有缺口。脚本和第三方规则导入后暂停，确认语义后再启用。

## 常用操作直接完成

在 Finder 中选中文件后打开右键菜单；也可在主窗口选择或拖入文件，再从操作库执行。默认快捷面板为 `⌥⌘O`，可在输入规则中修改。

| 要做的事 | 使用方式 | 需要更多选项时 |
| --- | --- | --- |
| 压缩为 ZIP / 7Z | 选择对应动作后直接创建；输出在所选第一项所在目录，同名自动另起名称 | “加密 / 分卷 / 自定义压缩…”可设置密码、分卷、格式与 7Z 固实压缩 |
| 解压一个或多个压缩包 | “解压到当前目录”或“直接解压”，默认每个包放入各自同目录的新文件夹；另有“展开到当前目录”入口 | “解压到其他目录…”或“查看包内文件…”可选择位置和提取部分文件 |
| 新建文本、Markdown、文件夹 | 从“新建”中直接选择类型；同名自动编号 | “自定义名称与内容…”保留名称与初始内容设置 |
| 转换图片格式 | 选择 PNG、JPEG、HEIC 或 TIFF，原目录生成新图，保留原文件 | “自定义格式与尺寸…”可调整尺寸与其他选项 |
| 复制路径、文件名、SHA-256 | 路径和文件名直接复制；SHA-256 计算完成后复制，无需再次确认 | 多个结果按行排列 |
| 复制或移动文件 | 选择桌面、下载、文稿即可执行；“选择其他目录…”只选一次目标目录 | 同名冲突会停止，不替换现有文件 |

普通压缩包直接解压；遇到需要密码的包时，先尝试该包在钥匙串中已有的密码，没有可用密码才询问。快捷解压中新输入的密码仅用于当前包、本次操作；批次继续时不会重新解压已完成项目。取消或出错会保留已完成结果并提示。

任务以小浮窗显示进度、结果或失败原因，可通过“显示结果”定位输出。需要耗时的快捷文件任务会排队。高级压缩、批量重命名预览、自定义新建和自定义图片转换仍保留设置界面。

## 初次使用与权限

打开主窗口即可搜索和运行无需额外权限的功能。按 `⌘,` 打开独立设置窗口，在“权限”页查看辅助功能、输入监控和 Finder 扩展的独立状态；“继续完成授权”会引导到尚未完成的系统设置，从系统设置返回后重新检测，也可手动点“重新检测”。macOS 的授权开关仍需在系统界面完成，应用不会自行改写授权数据库。

- 启用“搞操作访达扩展”后，用户主目录下系统支持的位置可显示菜单，包括桌面、下载、文稿和普通项目目录。系统服务也提供“搞操作…”文件入口。
- 辅助功能用于窗口调整和拖动、自动粘贴及锁屏；输入监控用于全局快捷键、鼠标按钮和方向手势。部分监听可通过辅助功能权限工作，权限页仍会分别显示两项授权状态；权限可用与监听被暂停是不同状态。
- 在“设置 → 窗口”中开启“拖动到屏幕边缘吸附”，直接拖动普通窗口标题栏到左右边缘半屏、顶部铺满、四角四分屏，无需快捷键或Option。可独立开启拖离恢复原尺寸。“Option＋左键拖动前台窗口”是另一项可选功能，两项出厂默认关闭，更新保留个人设置。窗口拖动还需辅助功能与输入监控权限。
- 剪贴板记录默认关闭，需在设置中明确启用；暂停或关闭后停止采集。
- 文件访问由 macOS 按实际目录管理；遇到提示时允许需要操作的目录，或通过“选择文件”“选择目录”指定项目。备用访达菜单、终端标签页和自定义脚本会按需请求自动化权限。第三方配置迁移需要对原配置的实际读取权限；无法读取时停止迁移。
- 开机启动由用户在设置中启用，应用不自动关闭其他增强工具。

## 剪贴板与窗口

先把光标放在要输入的应用中，再打开“查看剪贴板”小浮窗。搜索后可点击条目，或用上下方向键选择、回车粘贴；条目的右键菜单提供“复制”“粘贴为纯文本”“复制为纯文本”和固定操作。“粘贴当前纯文本”使用当前剪贴板内容，不需要启用历史记录。自动粘贴需要辅助功能权限；遇到安全输入、目标应用失效或剪贴板变化时会停止，可改为复制后手动 `⌘V`。小浮窗中的“管理”回到完整剪贴板页面。

窗口操作以打开面板前的目标窗口为对象；布局完成后将该窗口带回前台，便于继续工作。若目标窗口已关闭、应用退出、用户切换了其他应用，或目标不支持调整和提升，会显示原因。“恢复原位置”用于恢复本应用保存的窗口布局。

## 实际限制

- 访达扩展不是全系统右键注入。iCloud、OneDrive 等目录、第三方文件管理器和系统保护位置的菜单由系统决定；可使用快捷面板、系统服务或拖入文件。
- 实验多点触控依赖系统未公开接口，默认关闭，不能抑制系统原手势；压力、Magic Mouse 和复杂手势必须实机验证。高级键鼠替换可按规则消费事件；原有基础监听仍保留原始事件。
- 全屏窗口、不可缩放窗口、未提供辅助功能接口的应用可能无法按指定尺寸排布；最小尺寸和其他系统限制由目标应用决定。
- Option＋左键拖动与边缘吸附只监听输入，不吞掉目标应用原鼠标事件，目标应用可能同时执行选择或其他操作。输入暂停和应用排除也适用于这两项功能。
- 快捷键与第三方软件占用不能全部预先检测。支持本应用配置内冲突检测、按应用规则和暂停，应避免对同一快捷键叠加多套增强工具。
- 剪贴板文件记录保存的是引用，不复制原文件；原文件移走后引用可能失效。应用排除和敏感剪贴板标记可减少记录，但不能识别一切敏感内容。
- 文件操作不静默覆盖重名项目。恢复操作会校验文件是否已改变；变化后停止恢复，保护后续修改。
- Finder 菜单使用短时、一次性本机票据交接动作；旧式外部 URL 中携带的动作与文件路径只进入用户复核流程，不直接执行文件修改。该票据不提供对其他本机程序的身份认证。
- 压缩使用官方 7-Zip 和随包 Python 格式桥接，不提供 RAR 创建。支持 ZIP/7Z 中文密码、分卷和自动展开多层 TAR 容器；ACE/LZIP 等特殊格式只按已验证变体验收，ACE 加密、LZ77 和多卷仍未验收。
- ZIP/7Z 数字分卷可保留原件解压，自动移走分卷原件尚未支持：同名编号与解码成功不能证明相邻文件归属。
- 解压先隔离校验；“展开到当前目录”在冲突时停止，不覆盖现有内容。默认预算为展开 20 GiB、10 万项、一小时，可在设置调整。仅允许经过验证的包内相对链接，拒绝越界、循环、特殊文件和规范化重名；macOS 元数据限本应用支持的 AppleDouble 记录。格式支持不等于所有应用包均可运行。固实包逐文件解码可能较慢。
- 组合操作逐步执行，执行中已完成的外部系统动作不保证整体回滚。
- 使用本地 ad-hoc 签名，**未使用 Developer ID、未公证**。其他 Mac 的 Gatekeeper 可能要求在系统设置“隐私与安全性”中确认打开。项目不会自动关闭 Gatekeeper。
- 未提供桌面小组件或云同步。

## 本地资料

资料目录：`~/Library/Application Support/GaoSeries/GaoCaoZuo`。

- `settings.json`：设置、模板、收藏目录、输入规则、常用短语与组合操作。
- `receipts.json`：文件操作恢复记录。
- `finder-menu.json`、`FileEnhancements`、`ArchiveEnhancements`：右键、文件和压缩设置及模板索引。
- `Exchange`：跨应用交接包与状态记录；待确认、失败与中断包保留，超过容量预算时拒绝新交接。
- `replacement-migration.json`：第三方配置迁移状态与中断恢复快照（存在时）。
- `Clipboard/history.json` 与同目录 PNG、RTF：剪贴板记录及附件。
- 偏好文件（如存在）：`~/Library/Preferences/com.gaoseries.GaoCaoZuo.plist`。
- 安全备份：`~/Library/Application Support/GaoSeries/GaoCaoZuo-Backups`。

资料与备份采用当前用户私有权限。密码只在用户选择保存时进入 macOS 钥匙串；安装器不导出、重置或删除钥匙串。读取失败、格式不支持、附件无法读取时保留原资料并停止相关写入。资料不随 GitHub 源码、发行包或源码压缩包上传。

## 构建与检查

需要已安装 Xcode 命令行工具、Swift 编译器和 Python 3。从项目目录运行：

```sh
Scripts/test.sh
Scripts/build.sh
```

本版发行包构建到 `Release/GaoCaoZuo-1.05.dmg`，旁边生成 SHA-256 校验文件。临时构建目录位于系统临时目录，结束自动删除。只构建 `.app`：

```sh
Scripts/build.sh --app-only /private/tmp/GaoCaoZuo-review.app
```

目标须为不存在的绝对路径。正式更新前运行 `Scripts/bump-version.py`，版本精确增加 0.01、构建号增加 1；同次未交付修复不增号。

## 安全安装流程

```sh
Scripts/install.sh --app /绝对路径/搞操作.app --defer-cleanup
Scripts/finalize-install.sh --manifest /安装脚本输出的绝对路径/manifest.json --verified
```

安装前需退出搞操作。安装器核验应用身份与签名，完整备份本应用资料、附件和设置，并对每个文件计算 SHA-256。新程序在安装位置再次核验；主要功能验收前保留旧程序。验收失败可把最后一个参数改为 `--rollback` 恢复旧程序，用户资料与安全备份均保留。

仅在明确验收后删除本次暂存旧程序。仅当最新版 DMG 和校验文件完整可读时，才清理本项目 `Release` 里较旧版本、固定命名格式的发行包。不会扫描或删除其他应用的资料。
