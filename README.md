# 搞操作

搞操作是一款原生 macOS 操作增强工具，把文件处理、窗口控制、剪贴板、压缩包与自定义动作集中到一个操作库，通过主窗口、菜单栏、快捷面板、访达菜单、系统服务和输入规则调用。

当前源码：**V1.13 / build 14**（首版 V1.00 / build 1）。运行要求：Apple Silicon Mac、macOS 14 或更高版本。独立 Bundle ID：`com.gaoseries.GaoCaoZuo`。

逐项实现、迁移与未验收边界见[功能覆盖清单](Docs/功能覆盖-V1.09.md)。

## V1.13 更新

窗口恢复在整体尺寸未被接受时，先按目标应用已经接受的尺寸分轴重试，再核对保存的位置和尺寸。只有精确恢复才清除记录；仍受限制时失败并回滚，不把受限尺寸当作恢复成功。窗口身份、前台、取消和显示器核验保持不变。

## V1.08 更新

将自动输入法、划词、常用短语、快捷键速查与清洁模式接入同一生产动作目录、现有输入事件通道和设置窗口。自动输入法与双击修饰键触发默认关闭，使用真实已启用输入源和原生菜单；缺源、冲突、不可读组合状态、菜单歧义或目标身份变化会停止并说明原因。手工切换需明确指定一对来源，旧动作ID保留，不再猜选语言。

短语库保存稳定UUID、分组、标签、变量及富内容。面板输入 `:短语码` 可唯一定位并执行对应模式；剪贴板浮窗支持当前搜索结果的 `⌘1–9` 编号。CSV/XLSX为文本表格，原生 `.gaosnippets` 备份另保留附件和恢复版本，可由用户选择iCloud Drive存放；这属于显式备份／恢复，不是自动同步。文件引用不等于保存了原文件内容。

自动粘贴绑定原进程、窗口、输入元素与选区。macOS事件提交无法证明目标已消费剪贴板，发送后需核对实际插入结果，才能确认恢复原格式、保留当前内容或弹出堆栈；不会按固定时间换回旧内容。回车须另行确认且目标必须为可编辑文本区域。清洁模式须先用退出组合键验证现有活动通道，再允许最长180秒遮罩；不是系统锁屏。

ZIP及符合方法限制的未加密7Z改为单会话流式解码。解码器仍受只读沙盒限制，父进程逐成员核验路径、尺寸和发布条件；源包身份与全文SHA、元数据及恢复指纹继续检查。大批小文件无需为每一项重新启动解码器。压缩创建保持相同算法、等级、线程和校验，不以降低压缩率换取速度；实际速度需按固定样本比较。

跨应用面板检查安装版本的GaoAction能力声明。缺少提供方时禁用执行入口，并保留私有交接包导出；交接请求打开成功不是业务完成。本轮未自动启动应用或运行GUI／冒烟测试，真实菜单、权限继承、全局按键、多设备及双方交接闭环仍须与隔离检查分开判断。当前不宣称已完整替代四款原软件。

## 常用操作直接完成

在 Finder 中选中文件后打开右键菜单；也可在主窗口选择或拖入文件，再从操作库执行。默认快捷面板为 `⌥⌘O`，可在输入规则中修改。

| 要做的事 | 使用方式 | 需要更多选项时 |
| --- | --- | --- |
| 压缩为 ZIP / 7Z | 选择对应动作后直接创建；输出在所选第一项所在目录，同名自动另起名称 | “加密 / 分卷 / 自定义压缩…”可设置密码、分卷、格式与 7Z 固实压缩 |
| 解压一个或多个压缩包 | “解压到当前目录”或“直接解压”，默认每个包放入各自同目录的新文件夹；另有“展开到当前目录”入口 | “解压到其他目录…”或“查看包内文件…”可选择位置和提取部分文件 |
| 新建文本、Markdown、文件夹 | 从“新建”中直接选择类型；同名自动编号 | “自定义名称与内容…”保留名称与初始内容设置 |
| 转换图片格式 | 选择 PNG、JPEG、HEIC 或 TIFF，原目录生成新图，保留原文件 | “自定义格式与尺寸…”可调整尺寸与其他选项 |
| 复制路径、文件名、SHA-256 | 路径和文件名直接复制；SHA-256 计算完成后复制，无需再次确认 | 多个结果按行排列 |
| 复制或移动文件 | 选择桌面、下载、文稿即可执行；“选择其他目录…”只选一次目标目录 | 同名冲突会停止，不替换现有文件 |

普通压缩包直接解压；遇到需要密码的包时，先尝试该包在钥匙串中已有的密码，没有可用密码才询问。快捷解压中新输入的密码仅用于当前包、本次操作；批次继续时不会重新解压已完成项目。取消或出错会保留已完成结果并提示。

任务以小浮窗显示进度、结果或失败原因，可通过“显示结果”定位输出。需要耗时的快捷文件任务会排队。高级压缩、批量重命名预览、自定义新建和自定义图片转换仍保留设置界面。

## 初次使用与权限

打开主窗口即可搜索和运行无需额外权限的功能。按 `⌘,` 打开独立设置窗口，在“权限”页查看辅助功能、输入监控和 Finder 扩展的独立状态；“继续完成授权”会引导到尚未完成的系统设置，从系统设置返回后重新检测，也可手动点“重新检测”。macOS 的授权开关仍需在系统界面完成，应用不会自行改写授权数据库。

- 启用“搞操作访达扩展”后，用户主目录下系统支持的位置可显示菜单，包括桌面、下载、文稿和普通项目目录。系统服务也提供“搞操作…”文件入口。
- 辅助功能用于窗口调整和拖动、自动粘贴及锁屏；输入监控用于全局快捷键、鼠标按钮和方向手势。部分监听可通过辅助功能权限工作，权限页仍会分别显示两项授权状态；权限可用与监听被暂停是不同状态。
- 在“设置 → 窗口”中开启“拖动到屏幕边缘吸附”，直接拖动普通窗口标题栏到左右边缘半屏、顶部铺满、四角四分屏，无需快捷键或Option。可独立开启拖离恢复原尺寸。“Option＋左键拖动前台窗口”是另一项可选功能，两项出厂默认关闭，更新保留个人设置。窗口拖动还需辅助功能与输入监控权限。
- 剪贴板记录默认关闭，需在设置中明确启用；暂停或关闭后停止采集。
- 文件访问由 macOS 按实际目录管理；遇到提示时允许需要操作的目录，或通过“选择文件”“选择目录”指定项目。备用访达菜单、终端标签页和自定义脚本会按需请求自动化权限。第三方配置迁移需要对原配置的实际读取权限；无法读取时停止迁移。
- 开机启动由用户在设置中启用，应用不自动关闭其他增强工具。

## 剪贴板与窗口

先把光标放在要输入的应用中，再打开“查看剪贴板”小浮窗。搜索后可点击条目，或用上下方向键选择、回车粘贴；条目的右键菜单提供“复制”“粘贴为纯文本”“复制为纯文本”和固定操作。“粘贴当前纯文本”使用当前剪贴板内容，不需要启用历史记录。自动粘贴需要辅助功能权限；遇到安全输入、目标应用失效或剪贴板变化时会停止，可改为复制后手动 `⌘V`。小浮窗中的“管理”回到完整剪贴板页面。

窗口操作以打开面板前的目标窗口为对象；布局完成后将该窗口带回前台，便于继续工作。若目标窗口已关闭、应用退出、用户切换了其他应用，或目标不支持调整和提升，会显示原因。“恢复原位置”用于恢复本应用保存的窗口布局。

## 实际限制

- 访达扩展不是全系统右键注入。iCloud、OneDrive 等目录、第三方文件管理器和系统保护位置的菜单由系统决定；可使用快捷面板、系统服务或拖入文件。
- 实验多点触控依赖系统未公开接口，默认关闭，不能抑制系统原手势；压力、Magic Mouse 和复杂手势必须实机验证。高级键鼠替换可按规则消费事件；原有基础监听仍保留原始事件。
- 全屏窗口、不可缩放窗口、未提供辅助功能接口的应用可能无法按指定尺寸排布；最小尺寸和其他系统限制由目标应用决定。
- Option＋左键拖动与边缘吸附只监听输入，不吞掉目标应用原鼠标事件，目标应用可能同时执行选择或其他操作。输入暂停和应用排除也适用于这两项功能。

## 安全安装流程

```sh
Scripts/install.sh --app /绝对路径/搞操作.app --defer-cleanup
Scripts/finalize-install.sh --manifest /安装脚本输出的绝对路径/manifest.json --verified --verification-scope static-and-targeted --verification-evidence /实际核验记录.json
```

安装前需退出搞操作。安装器核验应用身份与签名，完整备份本应用资料、附件和设置，并对每个文件计算 SHA-256。新程序在安装位置再次核验；主要功能验收前保留旧程序。本版按用户偏好只进行静态与定向检查，实际核验记录须匹配候选库存摘要、版本与构建号，记录 `gui_verified=false`，不能据此声称GUI通过。人工业务验收另用默认 `manual` 范围。失败时单独运行 `finalize-install.sh --manifest <同一记录> --rollback` 恢复旧程序，用户资料与安全备份均保留。

仅在明确验收后删除本次暂存旧程序。仅当最新版 DMG 和校验文件完整可读时，才清理本项目 `Release` 里较旧版本、固定命名格式的发行包。不会扫描或删除其他应用的资料。
