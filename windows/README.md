# 搞操作 1.18 Windows x64

运行 `GaoCaoZuo-Windows-1.18-build1-x64-Setup.exe`，从开始菜单打开搞操作。本次 Windows 构建为 `1.18+1`。安装范围是当前 Windows 用户，支持从 `1.17+8` 原位升级。工作台用本机 Microsoft Edge 或 Google Chrome 的独立窗口呈现，使用单独的临时浏览器资料目录。程序和资料服务只监听 `127.0.0.1`。

托盘和输入线程按系统消息唤醒，关闭工作台后继续响应快捷键和原有后台任务。隐藏工作台时暂停剪贴板与选区的页面查询，重新显示后立即更新。

正常启动时，当前资料目录的已有会话会接收再次启动和资源管理器传入的文件。关闭工作台后，程序在通知区域留驻。单击图标或选「打开 搞操作」可恢复工作台。用工作台的「收起到通知区域」可保留正在录制或待确认的页面。托盘「退出」和工作台「退出搞操作」走同一退出流程。有录制、未保存结果或待确认粘贴时，可以返回处理或取消退出。退出会关闭本应用的热键、窗口和本机服务。Explorer 重建任务栏后会重新登记图标，图标的位置由 Windows 管理。CLI、`--serve` 和 `--no-browser` 启动无窗口服务，既有会话的文件转发由该会话处理。

Windows 资料沿用 `%APPDATA%\GaoSeries\GaoCaoZuo`，安装与卸载均保留这个目录。隔离运行可用 `GaoCaoZuo.exe --data-dir "D:\GaoTest"`。旧设置的未知字段继续保留。损坏、版本过新或已有别的资料却缺失主设置的目录会提示并停止写入。剪贴板历史默认关闭，关闭时不读取已有历史。用户明确保存的压缩包密码依压缩包指纹存入 Windows 凭据管理器。

工作台可用 `Ctrl+K` 打开动作库，按类别查找或直接输入关键词。窄窗口将左栏收进「导航」。截图、OCR、录制与交接共用同一页的标签。设置将外观、语言、历史和权限分组，编辑窗口可独立滚动表单并保留确认按钮。

输入规则和组合操作提供「试跑」。可用合成应用、触发条件和路径文本逐步查看条件是否匹配、预计产生的文件或动作、阻断原因和不确定项。试跑不打开样本路径，不执行规则、不生成文件。实际执行仍使用现有入口和确认流程。

## 工作台

| 页面 | Windows 入口与行为 |
|---|---|
| 工作台 | 日常工具、桌面与窗口、自动化和活动。跨页面搜索、收藏及最近操作共用同一动作目录。 |
| 文件 | 资源管理器右键「用搞操作打开」、工作台文件选择器、拖入路径文本和 `--paths`。支持原创空白 Office、新文件和文件夹、模板、批量重命名预览、目标目录复制移动、路径和 SHA-256。 |
| 压缩 | ZIP、ZipCrypto、AES ZIP、固实或非固实 7Z、数字分卷、包列表、定向提取及密码重试。未分卷 ZIP 和 7Z 可在预览中增删成员、清理隐藏项、保存到原包或另存新副本。 |
| 剪贴板 | 用户启用后收集能够核验的系统复制事件。在历史中搜索、固定、标注和复制。临时粘贴先核对普通文本目标，等待用户确认，剪贴板变化后放弃恢复。支持文字、图像、文件和文件夹堆栈。 |
| 小工具 | 图片 PNG、BMP、JPEG、TIFF、WebP、HEIF 和 ICNS 转换及最长边缩放，二维码，文件校验和系统控制。 |
| 截图与录制 | 区域、窗口、显示器、整桌面、多个窗口、取色、延时、自动长截图、标注、贴图、离线翻译与历史。可暂停录制、保存常规 MOV 与 M4A、提取 M4A 音频以及由视频生成 GIF。 |
| 窗口 | 工作区布局、恢复、选择窗口、最小化和最大化、可选边缘吸附和 Alt 拖动。Task View 和虚拟桌面切换使用 Windows 快捷键。窗口操作校验目标和执行状态，系统快捷键只返回提交结果。 |
| 图标换装 | 从当前用户桌面、开始菜单或文件选择器选取 `.lnk`。可预览原图标、按名称匹配角色、批量换装及恢复。 |
| 锁屏策略 | 使用本机闲置时间，默认关闭。执行前提示，活动或取消会终止本次倒计时。系统锁屏和屏保仅提交请求。 |
| 快捷键与手势 | 显式启用后注册全局快捷键。规则可按程序生效，支持中键、侧键和 Alt+右键方向手势。可选用 Windows iCloud Drive 目录同步规则，处理分支冲突及本机复核。 |
| 组合操作 | 按顺序调用同一个动作目录，失败时停止并保留已完成步骤。 |
| 活动 | 文件动作、截图历史入口和可校验的文件操作撤销。 |
| 设置 | 浅色、深色、跟随系统、通知区域图标、目录及剪贴板与输入等开关。可选择 Mac 语言目录中的 10 个界面语言。 |

## 图标换装

在「桌面与窗口 → 图标换装」选中需要修改的快捷方式，再点击角色卡片或为每行选择角色。确认列表后应用。选择已换装的快捷方式可恢复原图标。换装仅修改 `.lnk` 的图标位置、索引及图标专用字段，恢复时会核对快捷方式的完整指纹。其他程序已修改的快捷方式会跳过。记录只包含恢复图标所需的字段和指纹。

图库包含 ChatGPT、Claude、Gemini、Grok、DeepSeek、Kimi、GLM 和 Qwen 八款高清角色。可选择本机的 `AI-Mascot-Icons.exe` v1.0.0 或其解压目录导入原有五款 ICO，也可为单一角色选择自己的 ICO。导入后可在「优先使用本地图标」和「优先使用高清图标」间切换。原版 ICO 留在本机资料目录。 [原项目](https://github.com/Eclipse017/AI-Mascot-Icons) · [原版素材说明](https://github.com/Eclipse017/AI-Mascot-Icons/blob/v1.0.0/ASSETS.md) · [Windows Shell Link 格式](https://learn.microsoft.com/openspecs/windows_protocols/ms-shllink/)

## `ocr.files` 交接

在「截图与录制 → 历史与交接」选择 GaoAction V1 `.gaoaction` 请求目录，或把该目录通过资源管理器右键、`--gaoaction` 传入工作台。能力声明可用 `GaoCaoZuo-cli.exe --capabilities` 查询。审核页显示来源、识别参数和文件数。明确批准后才调用 WinRT 本机 OCR。请求和结果都使用 `.gaoaction` 目录扩展名，清单中的 `kind` 区分请求和结果。结果保留请求 ID、nonce、附件标识和源 SHA-256。单份 OCR 可校正文字，导出 TXT、Markdown、JSON 和带可搜索文字层的 PDF。识别语言取决于 Windows 已安装的 OCR 语言包。

`1.16+4` 修复了 Windows 下部分未改动文件被 OCR 交接误判为读取期间变化的问题。读取期间持有只共享读取的文件句柄，并重新核对路径身份与附件摘要。

搞文件或搞研究发起的请求可以在本机识别完成后回传待审核。提供方只使用 `%LOCALAPPDATA%\GaoSeries\GaoAction\OcrReturns-v1\<request UUID>` 下与已批准原清单相匹配的 `request.json`，在同目录原子发布 `result.gaoaction`。结果的 provenance 记录原请求清单 SHA-256。票据缺失、过期、校验失败或目标被占用时，工作台仍可导出结果。重试回传使用该任务已经生成的结果。接收方继续安排用户复核。

## 长截图、语言包与档案编辑

- 自动长截图只滚动用户选择区域下面的已核验 Windows 窗口。以像素重叠拼接，重复帧、焦点或位置变化和拼接不确定会停止。保留已核验的画面，可以手动续拍。
- 本机翻译支持简体中文和英语双向翻译及语言检测。经单次确认后下载选定的 Argos v1.9 语言模型，按固定 SHA-256 校验压缩包和推理文件。文本、截图及 OCR 结果只在本机处理。模型权重由用户按需下载。
- MOV 使用浏览器可用的 AVC/AAC 编码。仅录麦克风可交付 M4A，视频可提取 M4A，GIF 支持时间范围、裁剪和帧率。在目标编码不可用时仍可保存原始浏览器录制。系统共享音频取决于浏览器和所选媒体来源。
- 保存编辑前核对原件身份和摘要，预览后的外部变更会导致提交停止。候选包在临时目录重新解包并核对成员摘要及加密状态。原件模式用 Windows 文件替换，成功后移除暂时保留的被替换文件。另存模式拒绝同名覆盖。加密 ZIP 重打包为 AES，7Z 保持加密。
- Windows iCloud Drive 必须已登录并由 Windows Cloud Files API 识别。同步在选中目录下创建 `GaoCaoZuo-Windows-Rules`，存放按摘要命名的不可变修订。新规则、重新启用或动作变化要经过本机复核。不同分支改动同一规则时保留冲突，用户可以选本机或远端版本。Windows 规则和 Mac 专用规则采用各自的数据格式。Windows 只核对修订已写入本机同步目录，云端上传由 iCloud 客户端完成。

## 平台差异

- Windows 压缩包编辑由工作台预览承载。Finder Sync、Quick Look 插件、系统服务、Dock 和 AppleEvent 仍属 macOS 入口。
- 标注工程为 Windows 格式。录制使用浏览器媒体授权，系统音频与麦克风混合为单轨。部分窗口忽略定向滚动请求，可改为手动长截图。
- 部分外部窗口会限制激活、缩放、最小化或直接粘贴。自动粘贴面向可核验的非密码原生文本框。Windows 任务视图可管理虚拟桌面，程序没有任意桌面定位接口。
- Windows 复用 Mac 语言资源，补齐工作台长提示、Windows 长错误消息及原生截图和锁屏倒计时的 10 语言词条。系统文件选择器的系统控件采用 Windows 的语言。Windows 版提供原生窗口、Explorer、Windows 交互桌面及 Chromium 录制入口。原始触控、逐设备调校、部分电源与硬件控制、清洁模式输入遮罩，以及 Mac 版其他 GaoAction 能力不在此 Windows 交付范围内。
- 可在独立 Windows 窗口站验证应用的剪贴板写入、目标文本读取、确认和取消恢复以及并发内容保护。全局 `SendInput` 仍受 Windows 交互桌面限制。
- Windows 原生窗口截图已用显示器外的合成窗口做像素比对。Chromium 标签页录制已解码并核对合成画面与 M4A 音调。另用 Windows WASAPI 按测试进程回录了独立会话的合成音调。整屏录制与整机系统音频待有隔离交互桌面和专用音频端点时验证。本轮验收机器为 Windows 11，未接入 Windows 10 实机或实体输入、音频设备。
- iCloud Drive 的 Windows 注册、目录发现及同步读写使用 Windows Cloud Files 验证过合成提供方。实际 Apple 传输需要安装并登录 iCloud for Windows。本机没有安装该客户端。

## 构建与验证

需要 Windows x64、Python 3.11 或 3.12、Windows 内置 .NET Framework 编译器以及 Inno Setup 6.3 以上。面向用户的安装包内含 Python 运行时和 OCR 辅助程序。运行以下命令构建并验收。

```powershell
cd windows
pwsh -File .\build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
pwsh -File .\smoke.ps1
```

安装包和 `.sha256` 在 `dist`。构建候选时可用 `-DistDirectory build\candidate` 保留原发行文件，再运行 `smoke.ps1 -Installer <候选> -PreviousInstaller <上一版>`。仅验收安装、升级、卸载与界面词条时可加 `-LocalizationOnly`。冒烟用单独的安装目录、资料和随机卸载登记。开始菜单和资源管理器右键登记留给正式安装。浏览器回归、独立窗口站剪贴板、原生截图、媒体及 Cloud Files 测试源码保存在 `tests`。
