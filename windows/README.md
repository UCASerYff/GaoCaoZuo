# 搞操作 1.16 Windows x64

运行 `GaoCaoZuo-Windows-1.16-x64-Setup.exe`，从开始菜单打开搞操作。安装范围是当前 Windows 用户。工作台用本机 Microsoft Edge 或 Google Chrome 的独立窗口呈现，使用单独的临时浏览器资料目录。程序和资料服务只监听 `127.0.0.1`。设置里的通知区域图标开关控制关闭窗口后是否继续后台运行，从图标菜单可再次打开或退出。

Windows 资料沿用 `%APPDATA%\GaoSeries\GaoCaoZuo`，安装与卸载均保留这个目录。隔离运行可用 `GaoCaoZuo.exe --data-dir "D:\GaoTest"`。旧设置的未知字段继续保留。损坏、版本过新或已有别的资料却缺失主设置的目录会提示并停止写入。剪贴板历史默认关闭，关闭时不读取已有历史。用户明确保存的压缩包密码依压缩包指纹存入 Windows 凭据管理器。

## 工作台

| 页面 | Windows 入口与行为 |
|---|---|
| 工作台 | 日常工具、桌面与窗口、自动化和活动。跨页面搜索、收藏及最近操作共用同一动作目录。 |
| 文件 | 资源管理器右键「用搞操作打开」、工作台文件选择器、拖入路径文本和 `--paths`。支持原创空白 Office、新文件和文件夹、模板、批量重命名预览、目标目录复制移动、路径和 SHA-256。 |
| 压缩 | ZIP、ZipCrypto、AES ZIP、固实或非固实 7Z、数字分卷、包列表、定向提取及密码重试。预先核对成员路径与预算，再把结果从隔离目录移入目标。 |
| 剪贴板 | 用户启用后收集能够核验的系统复制事件。在历史中搜索、固定、标注和复制。临时粘贴先核对普通文本目标，等待用户确认，剪贴板变化后放弃恢复。支持文字、图像、文件和文件夹堆栈。 |
| 小工具 | 图片 PNG、BMP、JPEG、TIFF、WebP、HEIF 和 ICNS 转换及最长边缩放，二维码，文件校验和系统控制。 |
| 截图与录制 | 区域、窗口、显示器、整桌面、多个窗口、取色、延时、长截图、标注、贴图与历史。录屏与录音使用浏览器系统媒体选择器，可暂停和保存 WebM。共享系统音频取决于浏览器和选中的媒体来源。 |
| 窗口 | 工作区布局、恢复、选择窗口、最小化和最大化、可选边缘吸附和 Alt 拖动。Task View 和虚拟桌面切换使用 Windows 快捷键。窗口操作校验目标和执行状态，系统快捷键只返回提交结果。 |
| 锁屏策略 | 使用本机闲置时间，默认关闭。执行前提示，活动或取消会终止本次倒计时。系统锁屏和屏保仅提交请求。 |
| 快捷键与手势 | 显式启用后注册全局快捷键。规则可按程序生效，支持中键、侧键和 Alt+右键方向手势。鼠标规则保留原鼠标事件。 |
| 组合操作 | 按顺序调用同一个动作目录，失败时停止并保留已完成步骤。 |
| 活动 | 文件动作、截图历史入口和可校验的文件操作撤销。 |
| 设置 | 浅色、深色、跟随系统、通知区域图标、目录及剪贴板与输入等开关。 |

## `ocr.files` 交接

在「截图与录制 → 历史与交接」选择 GaoAction V1 `.gaoaction` 请求目录，或把该目录通过资源管理器右键、`--gaoaction` 传入工作台。能力声明可用 `GaoCaoZuo-cli.exe --capabilities` 查询。审核页显示来源、识别参数和文件数。明确批准后才调用 WinRT 本机 OCR，结果可导出为 `.gaoresult`。结果保留请求 ID、nonce、附件标识和源 SHA-256。单份 OCR 可校正文字，导出 TXT、Markdown、JSON 和带可搜索文字层的 PDF。识别语言取决于 Windows 已安装的 OCR 语言包。

## 平台差异

- 采用 Windows 工作台窗口、通知区域、文件选择和右键入口。Mac 的 Finder Sync、Quick Look 加密包原位编辑、系统服务、Dock、AppleEvent 和 iCloud 同步有各自的平台限制。Windows 版提供压缩包列表和选项提取。
- 长截图由用户滚动，程序核对窗口和重叠像素。翻译入口显示可用性。标注工程为 Windows 格式。浏览器录制为 WebM，视频、系统音频和麦克风可用性由系统授权和所选来源决定。
- 部分外部窗口会限制激活、缩放、最小化或直接粘贴。自动粘贴面向可核验的非密码原生文本框。Windows 任务视图可管理虚拟桌面，程序没有任意桌面定位接口。
- Windows 版界面文案为中文。原始触控、逐设备调校、部分电源与硬件控制、清洁模式输入遮罩，以及 Mac 版其他 GaoAction 能力尚有差距。

## 构建与验证

需要 Windows x64、Python 3.11 或 3.12、Windows 内置 .NET Framework 编译器以及 Inno Setup 6.3 以上。面向用户的安装包内含 Python 运行时和 OCR 辅助程序。运行以下命令构建并验收。

```powershell
cd windows
pwsh -File .\build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
pwsh -File .\smoke.ps1
```

安装包和 `.sha256` 在 `dist`。安装冒烟用独立目录和合成数据运行同一个安装器，测试用安装跳过用户级开始菜单、资源管理器和卸载注册。浏览器回归脚本为 `tests/workbench_browser_smoke.py`，使用隔离的 Chromium 用户目录。
