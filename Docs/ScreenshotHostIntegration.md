# 截图工作台宿主桥

实现位于 `Sources/ScreenshotHostController.swift`。宿主只持有一个 `ScreenshotHostController`，按需创建 `ScreenshotAppModel`；不会启动旧应用、创建第二个 `NSApplication`、注册独立菜单栏程序或在初始化时注册快捷键。

## 接入契约

- `init(data:onShowWorkspace:onHideHost:)`：资料以 `LocalData.directory/Screenshot` 为目标；备份位于宿主备份目录下的 `Screenshot`。构造控制器不创建模块资料，也不读取屏幕、声音或剪贴板。
- `workspaceView` / `settingsView`：完整截图、标注、OCR、录屏录音、翻译、历史与交接页面，以及截图资料迁移和设置。
- `receive(_:)`：复用来源图像、PDF、可编辑标注和交接包处理流程。交接由当前宿主的合约核验，不重放旧来源目标包。
- `performAction(_:files:)`：同进程动作入口。空输入仅展示 OCR、标注、翻译或录制页面。剪贴板动作必须使用独立、明确的 `screenshot.ocr.clipboard` / `screenshot.translate.clipboard` 动作。
- `operationBlockingReason`：由宿主提供清洁模式、粘贴事务、文件任务和资料保护状态。捕获、区域选择、长图、OCR、翻译与录制开始前检查。
- `captureInputExclusive`：仅在捕获、选择来源/区域、取色或录制活动时为真。宿主可将输入增强事件直通，避免吞掉选择与取消按键。静态未保存标注不会永久独占输入。
- `busy`：活动处理状态；`terminationBlockReason`：进一步保护未保存标注、OCR/校正草稿、翻译，以及未完成外部交接和贴图窗口。读取两者不会首次创建模型。
- `cancelActiveWork()`：请求取消捕获、OCR、翻译、可取消导出、外部交接及录制。录制依旧走原控制器取消并保留恢复材料的路径。
- `cleanupAfterApprovedTermination()`：仅在无退出阻断时关闭本模块工具并清理本次会话私有临时目录；不清理真实资料、备份或用户输出。

## 内容保留

标注文件原件保持不变；捕获产生的未保存图像和修改后的标注会阻止退出。替换标注、OCR 或翻译前需要处理现有未保存结果。OCR 尚未应用的逐行校正草稿保存在模型中，离开页面后仍可回到校正窗口继续。翻译输入、语言与结果跟随模型保留，回调按操作 ID 校验，旧页面的迟到退出回调不能覆盖新输入。

完整备份在后台调用同一生产 `ScreenshotDataBackup.create`，包含活动资料及已绑定迁移归档的复制、摘要核验与恢复复制演练。工作台显示不定进度及“不可取消”说明；期间暂停本模块新生产任务与设置保存，结束或失败都清除忙状态。失败保留来源和未完成备份，不清理真实资料。

工作台“当前工作”菜单可显式另存可编辑标注、结构化 OCR 和翻译草稿；使用新的唯一工作目录，不覆盖已有文件。结束工作和关闭临时贴图均由用户明确操作。正在处理的任务与外部交接不能通过结束工作绕过。

截图设置的迁移路径是“预览来源/摘要/冲突 → 明确确认备份并迁移”。无来源证据时才允许明确初始化。中断恢复要求指定迁移编号并再次确认。UI 不自动执行迁移、恢复、权限申请、语言包下载或历史采集。

## 迁入记录与来源退役（2026-11-03）

“历史与交接”中的“迁入的恢复文件与历史交接”由用户点击读取。它只读取接收方ImportedActivity，核原记录与附件，不调用live Exchange接收/发送入口，也不修改旧manifest、provider、nonce和结果状态。可查看或另存原记录、单独导出附件；旧交接不形成可重新执行的队列。未完成、孤立、缺实物或关联矛盾的事务显示阻断原因及安全处理路径。

“打开OCR恢复稿”先核恢复JSON与原件闭包，再经现有未保存确认载入OCR控制器；只恢复已保存页面、校正、几何和来源映射，不自动识别、重试或回送。哈希验证在后台，期间当前文稿或处理代际变化则拒绝替换。“检查并另存录制恢复”只处理接收方同目录的原journal/partial，使用原媒体解码核验与无覆盖恢复路径；不可解码时保留现用文件，不报告修复成功。

Root在实际迁移与验收后，使用同一生产CLI的retirement-preview与finalize-source-retirement显式生成最小不可恢复收据。没有合法finalized收据时仍保护原迁移归档；合法收据使启动与schema3现用资料备份只依赖目标marker/收据/ImportedActivity，不再读取纯旧Archive。原来源及专属备份的精确删除仅由Root执行，代码只给白名单与需人工核对范围。接收方现用Settings/History/Pins/恢复文件/历史交接不能作为旧备份删除。

本说明不代表新范围已经完成编译、真实业务或安装验收；候选和CLI以对应来源摘要的实际核验记录为准。实现阶段不运行GUI、采集、真实迁移、退役finalize、安装或来源删除，不自动运行冒烟。
