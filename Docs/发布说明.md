# 搞操作 V1.01

构建号 2，2026-10-08；从 V1.00 增加 0.01，构建号增加 1。

- 图标沿用搞系列纯灰底、白色竖排“操作”，字形按同系列实际视觉大小等比缩小。
- 修复 Finder 菜单将操作交给安装暂存中的旧程序的问题。菜单读取当前所选文件，显式交给扩展所属的主程序预览，并禁止其他路径的运行实例替代。
- 安装、回滚与清理时精确核验并处理本应用和 Finder 扩展的登记。运行中的旧程序或登记失败会停止清理，保留资料、旧程序与安全备份。
- 保留统一操作面板、文件工具、窗口控制、ZIP/7Z 压缩、剪贴板、快捷键、鼠标方向手势和组合操作。

已通过文件与压缩回归（56 项）、图标和资料保护检查，以及安装器的备份、回滚、精确登记回归。实际 Finder 菜单、启动和 ZIP 创建另行进行本机界面验收。

Apple Silicon、macOS 14 或更高版本。本版使用本地签名，未公证。窗口和输入模块需要用户授予相应系统权限；Finder 扩展需要启用。全屏窗口、第三方输入工具并存等场景受系统限制；未提供桌面小组件或全局多点触控手势。
