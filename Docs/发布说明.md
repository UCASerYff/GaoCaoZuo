# 搞操作 V1.05

构建号 6，2026-10-13；从 V1.04 增加 0.01，构建号增加 1。

修复 Finder 排除规则和点击复核，保留未知设置字段及自定义标题；旧默认 iShot/DiskMap 名称迁移为实际搞系列动作名称。终端与编辑器采用各自的自动化或命令行入口，路径按数据传递。Terminal仅支持安全新窗口，无法证明新标签身份时明确拒绝，iTerm使用其明确新会话接口。

GaoAction V1 增加严格请求、结果、参数、附件与路径校验，以及私有复制和持久状态记录。重复结果不重复执行；中断状态不自动重放。跨应用任务可复核结果、定位交接包及主动重新递交。打开提供方只表示文档递交，业务完成以经校验和确认的结果为准。搞操作不声明搞文件、搞机灵或搞截图的提供方动作。

压缩修复安全硬链接与合法CPIO链接计数，ZIP/7Z数字分卷的原件自动后处理明确拒绝，全部原卷保留：解码成功不能证明同名前后卷都属于该包。普通保留原件的解压继续可用。新增原创 AR、CPIO、CAB 与 ISO 样本回归；TAR 容器不声明创建。Quick Look 保持进程内只读目录与预算限制，新增通过公开宿主接口选择压缩包的面板入口；宿主不支持时提供 Finder 手动打开指引。包内预览、选择提取和增删在主程序进行。

压缩的文件准备、命名、哈希与提交改为后台执行，取消等待实际工作结束。结果发布、回滚和原件恢复由系统原子拒绝同名覆盖；单项或末项原件处置期间取消也进入恢复，冲突时保留两份文件并明确报告。

输入设备来自真实IOHID记录，不以虚构能力或保存参数代替硬件验证。增加边缘分段、菜单路径选择与执行、重复按键抑制及窗口进程启动身份校验；合法空启动日期使用可验证的内核启动标识，仍拒绝PID复用和身份读取失败。异步恢复继续核验实际布局。

普通标题栏拖动的边缘吸附独立于快捷面板和Option拖动；左右半屏、顶部铺满、四角四分屏。修复拖离恢复尚未完成时快速松手的竞态，松手等待实际恢复结束；暂停或切换应用仍取消。开关更新时保留个人设置，出厂默认关闭。

本地化资源接入主程序与两个扩展；主程序即时切换，Finder使用当前设置快照，Quick Look跟随系统语言。语言目标包括简体中文、英语、日语、德语、法语、西班牙语、韩语与葡萄牙语。仍有待译界面及动态错误，回退可见，不宣称完整多语言覆盖。

本版仍未达到四款竞品的完整替代条件。原生WPS/Ai模板、第三方私有规则与密码完整迁移、截图/清理提供方、特殊压缩变体、Magic Mouse、多键鼠标、多屏和跨宿主实机验收仍有缺口。四款原软件保留，未执行卸载。

测试入口为 `Scripts/test.sh`。自动测试覆盖源码与临时生成样本，不能代替真实硬件、目标应用及系统权限验收。每轮具体证据保存在本机私有TestResults，不随公开发行包上传。

采用本地ad-hoc签名，未使用Developer ID，未公证。系统权限由本人在系统设置确认，未修改TCC数据库或关闭Gatekeeper。安装器新增prepared各移动边界回滚和部分注销失败恢复；安全安装核验并备份本应用资料、设置和附件；失败恢复旧程序，保留资料、钥匙串和备份。
