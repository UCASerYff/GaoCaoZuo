# 搞操作 V1.03

构建号 4，2026-10-12；从 V1.02 增加 0.01，构建号增加 1。

本版扩展常用文件、压缩、输入和窗口能力，并补充失败恢复与配置迁移保护。普通文件操作直接执行，需要参数或预览时保留高级界面。

- Finder 菜单可开关、改名、排序、分组、排除目录，支持工具栏菜单与常用目录、模板、应用入口；兼容系统从后台线程请求菜单，避免扩展崩溃；使用系统支持的菜单标记传递动作，修复菜单点击无响应。
- 文件工具增加剪切粘贴及中断恢复、隐藏/扩展名/权限、名称修复、目录解散、更多摘要、WebP/ICNS及图标集；内置九种原创有效文档模板，包括 Pages、Numbers 和 Keynote。
- 压缩增加等级/线程、分别打包、忽略规则、日期、中文密码 ZIP、原目录展开、递归 TAR、包内安全链接和 macOS 元数据往返；新增目录树预览、包内编辑、钥匙串密码本与 Quick Look 扩展。
- 窗口增加 2/3、中间半屏、自定义布局、最大高度/宽度、吸附预览和脱离恢复。高级输入增加键鼠事件规则、滚轮、绘图、边角、脚本及文件夹同步；原始多点触控为默认关闭的实验功能。
- 迁移只转换已知设置，原配置先独立核验备份；未知规则保留说明，导入规则和脚本暂停。多文件迁移保留事务快照，支持中断恢复。剪贴板历史原有开关保持不变，凭据不导出。

本版不能宣称已完整替代四款原软件。原生 WPS/Ai 模板、iShot 截图/贴图接口、部分系统手势和设备调校、部分特殊压缩变体以及无硬件可验收的 Magic Mouse/多屏仍有缺口；四款原软件保留。每个功能的本机验收报告不随公开发行包上传。

测试入口为 `Scripts/test.sh`；包含安装与数据保护、模板结构、迁移恢复、菜单、窗口/输入规则、文件、真实压缩样本、任务队列及旧功能回归。自动测试通过不代表所有硬件或系统 UI 已验收。

采用本地 ad-hoc 签名，未使用 Developer ID，未公证。更新后若 macOS 要求重新确认权限，需本人在系统设置完成。未修改系统授权数据库或关闭 Gatekeeper。
