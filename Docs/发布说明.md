# 搞操作 V1.00

首个独立版本，构建号 1，2026-10-08。

- 提供统一动作入口，覆盖文件操作、窗口排布、压缩包、剪贴板、自定义快捷键、鼠标方向手势和组合操作。
- 提供主窗口、菜单栏、独立设置窗口、系统文件服务与 Finder 扩展；窗口标题显示版本。
- 设置中的“窗口”页提供默认关闭的 Option＋左键拖动与屏幕边缘吸附开关；按需授权，支持应用排除与暂停监听。特殊窗口与原应用输入行为可能限制效果。
- 文件修改遵循重名停止、操作前预览与校验恢复。压缩包在隔离目录提取后提交，拒绝危险路径和链接。
- 剪贴板历史默认关闭；启用后支持保留期限、应用排除和附件。密码使用钥匙串。
- 图标沿用搞系列的纯灰底与白色竖排书法字样，背景由代码确定性绘制；较密的“操作”字形按系列图标实际视觉大小等比缩至 512 像素高。
- 构建脚本生成 arm64 macOS 14+ 应用、DMG 和 SHA-256；应用与嵌入组件分别本地签名。
- 安全安装支持完整资料和附件备份、逐文件校验、安装后验收与旧程序回滚。

本版未公证。窗口和输入模块需用户授予对应系统权限；Finder 扩展需手动启用。云盘及系统保护目录、全屏窗口、第三方输入工具并存等场景存在系统限制。未提供桌面小组件或全局多点触控板手势。

自动化与人工验证结果以实际交付时的验收记录为准；功能存在不等于已在所有第三方应用、显示器和鼠标型号上验证。
