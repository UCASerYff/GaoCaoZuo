# 搞操作 V1.02

构建号 3，2026-10-11。本次从 V1.01 增加 0.01，构建号增加 1。

本版把常用文件动作改为选择后直接完成，保留需要设置参数的高级入口。

- Finder 右键可直接压缩 ZIP / 7Z，自动避开同名输出；加密、分卷与固实压缩放在“加密 / 分卷 / 自定义压缩…”中。
- 支持多选压缩包，逐个解压到各自同目录的新文件夹。只有需要密码且无可用已保存密码时才询问；继续操作不会重复解压已完成项目。“解压到其他目录…”和包内文件预览保留位置及选择提取功能。
- 文本、Markdown、文件夹直接新建；PNG、JPEG、HEIC、TIFF 直接转换并保留原图。自定义名称、内容和尺寸仍有独立入口。
- 路径和文件名直接复制，SHA-256 计算后复制。复制或移动到桌面、下载、文稿可直接执行，其他目录只需选择一次；同名冲突不覆盖。
- 快捷文件任务提供等待队列和结果小浮窗，能够显示结果位置、失败原因以及压缩任务的取消入口。
- 剪贴板新增搜索小浮窗，支持点击或回车粘贴、纯文本粘贴和回到完整管理页。历史记录仍默认关闭；使用当前剪贴板的纯文本粘贴不启用历史采集。
- 窗口布局后返回原目标窗口；目标失效、用户切换了其他应用或窗口不支持操作时显示原因。
- 权限页分别显示辅助功能、输入监控与 Finder 扩展状态，提供逐项引导和返回后检测。文件目录访问仍由 macOS 按需授权，不需要屏幕录制、完全磁盘访问或自动化权限。
- Finder 菜单使用一次性本机票据交接动作；旧式外部链接携带的动作和路径继续由用户复核。该票据不等同于本机程序身份认证。

原设置、剪贴板附件、恢复记录与钥匙串凭据继续使用原路径。更新安装仍须备份和核验资料，主要功能验收完成后再清理旧程序；本说明不表示安装或验收已经完成。

适用于 Apple Silicon、macOS 14 或更高版本。本地签名、未公证。Finder 菜单受系统目录支持范围限制；特殊或全屏窗口、输入工具并存和安全输入状态可能影响操作。压缩仍受格式、危险链接和展开预算限制；RAR 不支持创建，多层容器逐层处理。未提供桌面小组件、云同步或自由多点触控手势。
