# 搞操作 V1.08

构建号9，由V1.07/build8递增；面向Apple Silicon、macOS14及以上。

自动输入法、划词、富短语、快捷键速查与清洁模式接入现有动作目录、输入通道和独立设置页。输入源按稳定ID选择，缺失／冲突配置保留；菜单选择器保存真实应用、角色、路径及快捷键证据，执行前重新解析。安全输入和不明确的IME组合状态保守停止，不另建第二套全局事件tap。新增自动功能默认关闭，保留原规则与采集选择。

短语库增加稳定UUID迁移、分组标签、变量、富RTF／图像／文件附件与有界的原名副本。CSV及真正的XLSX用于文本表格，原生.gaosnippets备份保留富附件和恢复链；支持导入预览、冲突策略及撤销。用户可选择iCloud Drive存放显式备份，不宣称实时同步；外部文件引用与文件内容副本分开说明。

选区写回绑定原进程启动身份、窗口、元素、range、摘要、时限与generation；失效时显示可复制结果。自动粘贴单一事务保留原格式，事件发送后须核对实际插入再确认恢复／保留及堆栈提交；不按固定延迟换回剪贴板，不自动发送回车。清洁模式须先验证退出通道，最长180秒，带权限／事件通道检查和故障释放；不是系统锁屏。

ZIP与受支持的未加密7Z改为一次解码会话，保留只读沙盒、源包完整SHA、路径／容量／链接和元数据核验。目录解析及验证移出主线程，原目录展开保持同一事务，减少重复全文指纹计算。压缩创建保持同一算法、等级及校验；不能用解压收益推断创建提速或竞品等速。

跨应用面板按已安装版本能力声明启用动作，未就绪可导出有时限的私有交接包。请求打开成功不等同业务完成，双方确认／取消／结果回送须分别验证。

本轮未自动启动应用、浏览器或测试窗口，未运行冒烟测试；验证范围为编译、隔离资料与定向逻辑／CLI归档样本。真实全局输入、系统权限继承、Finder／Quick Look宿主、多屏／专属设备以及提供方端到端流程未据此标通过。WPS／Illustrator合法原创模板、部分设备调校及复杂格式等仍有缺口，完整替代四款原软件尚未达成。

采用本地ad-hoc签名，未公证。沿用原资料路径和钥匙串，安装前核验备份；静态与定向验收的安装记录明确gui_verified=false，失败保留恢复材料。用户资料、附件、长期备份与私有验收证据不进入GitHub或公开源码包。
