# 搞操作 V1.09：29项改进与验收记录

源码V1.09 / build 10，2026-10-17。本轮从实际V1.08/build9继续修改，保留已有逻辑。“实现”“定向通过”“真实宿主通过”分别判断；入口、编译和迁移complete不作为完整替代证据。

没有自动冒烟，没有启动搞操作主程序、Finder/QuickLook测试窗口或Cleaner。按清单指定的Office流程，仅用三份隔离模板副本执行原生编辑和重开；这不构成搞操作GUI验收。未执行的全局输入、硬件、权限和跨App项目没有据组件检查标通过。

## 本轮证据

- Finder：101项票据、未知字段、排除、目标快照与显隐纯逻辑；18项对象适配，其中隔离目录的真实shell `cd/pwd`核对中文/空格/引号路径；扩展源码类型检查。需要WindowServer的7条旧菜单渲染断言未在CLI执行，原断言保留。
- 模板：9种资源结构检查；DOCX/XLSX/PPTX内容类型、关系、空作者、隐私标记及无宏/外链检查。Word/Excel/PowerPoint 16.113.4分别打开副本、编辑、保存、关闭、重开；界面与磁盘均确认修改。原发行模板未改动，没有代点许可或认证。
- 输入：52项AutoInput/FlyKey、49项设备/边段/优先级、66项增强逻辑、26项生命周期、67项BAB和Cleaner离线安全检查。内部重复调用不累加覆盖；真实历史输入快照另作本轮只读重解析，脚本未执行。
- 客户端/窗口/剪贴板：94项GaoAction、16项目标模式、39项进程身份、30项异步焦点、49项布局/拓扑、60项粘贴事务，以及敏感复制观察、竞态、摘要和完整格式恢复。窗口使用模拟后端，不是移动真实外部窗口。
- 归档：60项流/FD/快照、52项真实生产小样本、88项原生QuickLook组件。外层受限首轮被拒后，以授权本地命令运行，生产只读沙盒仍启用。格式分六能力记录，见[归档矩阵](归档格式矩阵-V1.09.md)。
- 资源：新增138条八语言显式行及最终有效catalog占位符检查，原476条扩展资源检查通过。`Scripts/audit-localizations.py`记录逐文件候选、动态字符串及回退；不是GUI布局或完整提取覆盖率。

## 提供方接口交接

本轮仅改搞操作，没有修改、安装或清理兄弟项目。

- 搞截图：继续使用已安装表声明的capture.region/window/display、images.pin/annotate、OCR和translate。双方验收分别需要确认/取消/权限、实际产物及关联result回送，不能把打开请求当完成。
- 搞机灵：实际表的storage.inspect仅metadata并需一个directory引用；cleanup.review不接受附件/引用且只复核；apps.uninstall.review需一个application引用。重复文件/相似图只有真实引擎和声明均存在才启用；搞操作不替对方清理、卸载或生成receipt。
- 搞文件：保留documents.open/newText；真实新文档、双方确认及结果回送仍单列未验收。

超级右键专业版、BetterAndBetter、FastZip、Pane均为**部分替代，未达完整卸载条件**。主要未完条件是专属设备/多屏、合法复杂归档样本、真实后端、宿主/权限/跨App流程、全界面翻译布局与实时同步；原因逐项区分，不能合称“只差测试”。
