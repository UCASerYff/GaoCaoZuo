# 搞操作 V1.08 功能覆盖与验收边界

适用源码版本：V1.08 / build 9。范围按任务01的四款产品、任务02的六项扩展分别记录。功能入口、配置迁移完成、编译成功、测试样例通过和真实工作流验收是不同结论。本说明不构成任何原软件的卸载结论，也不描述其当前安装或备份状态。

本轮遵守用户的测试偏好：不自动运行 smoke test，不为验收启动应用、浏览器、模拟器或测试窗口。允许的验证为静态检查、编译、隔离单元／集成检查及明确授权的 CLI 归档基准。未访问真实系统剪贴板进行粘贴测试，未重做全局按键、实体退出键、真实窗口或扩展宿主验收；安装核验范围使用 `static-and-targeted`，`gui_verified=false`。历史真人测试不能代替本版新签名的实机证据。

## 状态及本轮证据

- **已实现并CLI实测**：对应生产逻辑已通过列明的隔离命令行样例；只适用于该样例和路径。
- **部分**：已有可用实现，但原任务仍有子项、生产入口或完整工作流缺口。
- **未实现**：当前代码没有完成该项真实能力；保存意向字段或提供交接入口不改变此状态。
- **未验收**：代码存在，但本轮没有对应真实设备、宿主、授权或用户流程证据，可与“部分”同时出现。
- **系统限制**：当前采用的系统 API 或宿主存在明确限制；不据此推断所有系统、设备或其他实现均不可行。

## 共用集成、迁移与完整替代结论

统一动作与`RuleContext`由`ActionDescriptor.swift`、`ExtensionActionCatalog.swift`、`OperationStore.swift`及App接线复用。自动输入法、FlyKey、清洁与原输入规则共用现有事件通道；关闭、暂停、设置保存失败和资料保护状态有对应停止路径。E1／E3／E4证明所列策略与入口，不能推断所有异步业务目标均已经过真实系统验收。
